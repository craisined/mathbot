# Mathbot
---

Mathbot is a discord bot for easy event registration in a Discord server. Built for the PHHS Math Team!

## Functionality
- Create, delete, and archive events
- Automatically create channels and user roles

## Setup
```bash
git clone https://github.com/craisined/mathbot.git
cd mathbot
pip install -r requirements.txt
python3 main.py
```
